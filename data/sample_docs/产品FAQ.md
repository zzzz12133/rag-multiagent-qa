# 产品常见问题 FAQ

## 账号与登录

- 忘记密码：在登录页点击「忘记密码」，通过注册邮箱或手机号验证码重置。
- 修改密码：登录后进入「个人中心 → 账号安全 → 修改密码」。
- 账号被锁定：连续 5 次输入错误密码将锁定 30 分钟，可联系客服人工解锁。

## 会员权益

- 普通会员：每日可查看 10 条内容。
- 白银会员：每日可查看 50 条内容，支持批量导出。
- 黄金会员：无限查看，支持高级筛选与 API 调用。
- 会员有效期从开通之日起算，到期自动降级。

## 数据导出

- 数据导出支持 CSV 与 Excel 两种格式。
- 单次导出上限为 10 万条记录，超过请分批次导出。
- 导出任务在后台执行，完成后会通过站内信通知下载。

## 其他

- 客服工作时间：工作日 9:00-18:00，节假日以公告为准。
- 投诉与建议可发送至 support@example.com。
